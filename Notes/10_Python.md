# Python

Python is an __interpreted, object-oriented, high-level__ programming langauge wth dynamic semantics.

## Why Python?
- Encourages very readable and well-structured code
- Rich ecosystem of libraries and frameworks
- Free and open source, widely spread, with a vibrant community

## Overview of Python
*refer to `hello.py`*

All things in Python are __objects__
- `type()` to see type
- `dir()` to see methods
- to use a method of an object, use `_.method()`
    - __most__ methods will return a __new__ object, they will likely not modify the current object
- to get/set an attribute of an object, use `_.attr`

Type conversion is simple in Python
- `<type>(<var>)`
    - Ex: `int('59') = 59` (that is an int)
