# C: Data Representation

First: data can be analog or digital
- __analog__: Analog systems deal with a smooth or continuous range of values
- __digital__: Digital systems deal with discrete values (only a fixed number of possible values)

## Endianness - the byte order
__Big Endian__ - the __most significant byte__ comes __first__ in memory (lower address)

__Little Endian__ - the __least significant byte__ comes __first__ in memory (lower address)

Most machines these days are __little endian__. But, network protocols use __big endian__.
